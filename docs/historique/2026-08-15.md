## 21:30 — Réalisé : le module PowerShell tourne aussi hors Windows

**Demande :** peut-on développer les deux plateformes depuis le Mac ? puis corriger les
deux accrocs relevés.

**Constat, mesuré sur la machine :**
- `go test ./...` passe entièrement sur le Mac, winget compris (joué contre
  `internal/winget/testdata/*-fr.txt`) et scoop compris (faux arbres `t.TempDir()`).
- `GOOS=windows go build` et `GOOS=windows go vet ./...` passent aussi — harnais ConPTY
  compris : le code Windows se vérifie à la compilation depuis le Mac.
- `tests/smoke.ps1` donnait **60 assertions sur 62** avec deux contournements ; il en donne
  **62 sur 62** sans aucun après ce commit.
- Restent Windows-only : `tests/conpty` (`//go:build windows`) et tout ce qui passe par les
  vraies CLI winget et scoop.

**Actions :**
- `shell/jigger.psm1` — le répertoire de cache par défaut suit désormais `os.UserCacheDir()`
  de Go sur les trois plateformes. `Join-Path $env:LOCALAPPDATA` était évalué avant même de
  regarder `JIGGER_CACHE_DIR` : sur macOS la variable est nulle, et l'`Import-Module`
  échouait net, avant la moindre ligne utile. Vérifié : le module et le binaire donnent le
  même chemin (`~/Library/Caches/jigger`).
- `tests/smoke.ps1` — le binaire est cherché sous ses deux noms (`jigger.exe`, puis
  `jigger`), et les replis de touches sont comparés aux liaisons **relevées avant
  l'import** au lieu d'être écrits en dur. Les deux échecs restants venaient de là :
  PSReadLine lie `⇥` à `TabCompleteNext` sous Windows et à `Complete` ailleurs, `Échap` à
  `RevertLine` sous Windows et à rien ailleurs. Ce n'étaient pas des défauts du module.
- `README.md` — la section Tests dit comment lancer la suite PowerShell depuis macOS ou
  Linux, et ce qui exige encore Windows.

**Décisions / notes :**
- Table ordinale pour les liaisons relevées, comme côté module : les tables de hachage de
  PowerShell ignorent la casse, or `Ctrl+C` et `Ctrl+c` sont deux liaisons distinctes.
- Le garde `$PSVersionTable.PSVersion.Major -lt 6 -or $IsWindows` court-circuite exprès :
  sous Windows PowerShell 5.1, `$IsWindows` n'existe pas et le mode strict refuserait de
  l'évaluer.
- La passe Windows se fera sur la machine Windows d'Yves, pas dans la VM Parallels.
